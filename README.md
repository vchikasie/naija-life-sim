# naija-life-sim

Naija Life — Hustle & Survive is a small browser game prototype built in plain HTML, CSS, and JavaScript.

How to play
1. Open `index.html` in your browser.
2. Use the buttons to work, hustle, eat, rest, study, and exercise.
3. Balance your money, hunger, energy, mood, and health.
4. Reach `₦ 3,000` without collapsing from hunger or exhaustion.

Files
- `index.html` — main page
- `style.css` — styling
- `script.js` — game logic

This is a simple starter version, and it can be expanded with more systems, NPCs, mini-games, and save progression.
