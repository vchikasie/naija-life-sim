# How to Play Naija Life Locally

## Quick Start (Easiest Method)

### Option 1: Direct Browser Opening (Windows/Mac/Linux)

1. **Download** all files from this repository:
   - index.html
   - style.css
   - script.js

2. **Save them in the same folder** (e.g., create a folder called "naija-life-game")

3. **Double-click `index.html`** - it will open automatically in your default browser

4. **Start playing!** The game loads instantly.

---

## Option 2: Using Python (If you have Python installed)

### Windows:
```bash
# Navigate to your game folder in Command Prompt, then:
python -m http.server 8000
```

Then open your browser and go to: `http://localhost:8000`

### Mac/Linux:
```bash
# In Terminal:
python3 -m http.server 8000
```

Then open: `http://localhost:8000`

---

## Option 3: Using VS Code (Recommended for Developers)

1. Install **Live Server** extension in VS Code
2. Right-click `index.html` → **Open with Live Server**
3. Game opens automatically

---

## Option 4: GitHub Pages (Play Online)

The game is already hosted online at:
**https://vchikasie.github.io/naija-life-sim/**

Just click that link and play instantly. No download needed!

---

## Troubleshooting

**Problem:** Browser shows a blank page or code instead of the game.

**Solution:** Make sure all 3 files (index.html, style.css, script.js) are in the **same folder**.

**Problem:** Files don't download.

**Solution:** Go to https://github.com/vchikasie/naija-life-sim and click the green "Code" button → Download ZIP → Extract all files.

---

## Game Controls

Once the game loads:
- Click any action button (Work, Hustle, Eat, Rest, etc.)
- Watch your stats change
- Try to reach ₦3,000 without dying
- Use the reset button to play again
